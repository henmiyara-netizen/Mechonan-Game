# מסע חכם בגלקסיה — Mechonan Galaxy

משחק PWA בעברית RTL להכנה למבחן המחוננים שלב ב'.
משחק חלל בסגנון Galaxy Attack עם שכבת ידע: שלבי ירי, שדרוגים על תשובות נכונות, מבחני בוס כל 10 שלבים.

## 🚀 משחק
פתח את האתר בכרום — ולחץ "התקן אפליקציה" כדי להעביר אותו למסך הבית כאפליקציה רגילה (פועל offline).

## 🎮 שליטה
- **עכבר**: גרור על המסך — החללית תעקוב + תירה אוטומטית
- **מקלדת**: חצים לתזוזה, רווח לירי
- **מגע**: גע וגרור על המסך — עובד על טאבלט/נייד

## 🛠️ פיתוח (לעצמי)
- ארכיטקטורה: PWA + Vanilla JS + Canvas — ללא bundler
- תוכן ב-JSON (`src/content/questions/`) — הוספת שאלות = עריכת JSON ללא קוד
- 6 פרקים לפי מבנה מבחן המחוננים: חשבון, השלמת משפטים, יחסי מילים, צורות, סדרות בצורות, יוצא דופן
- 8 חלליות עם יכולות ייחודיות

## ©️ קרדיט
שאלות המבחן מבוססות על חוברות מכון מיחונן (mihonan.co.il) שנרכשו על ידי המשתמש לשימוש אישי במסגרת הכנת ילדו למבחן.
